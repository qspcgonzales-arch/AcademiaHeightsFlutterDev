# Academia Heights — Flutter & Flame Mobile Edition

A 2D top-down school adventure game. Explore the campus, collect study
materials, talk to your instructors, and pass the **Prelim**, **Midterm**,
and **Finals** for each course to graduate.

Rebuilt from the original Java version for **ITE 013 — Application
Development and Emerging Technologies**, T.I.P. Quezon City, Section DS41S1.

| | |
|---|---|
| Genre | 2D Top-down Adventure / Educational Simulation |
| Platform | Android (built with Flutter) — iOS is a stretch goal |
| Engine | [Flame](https://flame-engine.org/) on top of Flutter |
| State | `provider` |
| Storage | `shared_preferences` (on-device only) |

## First-time setup

This repo contains the Dart/Flutter source only. The platform folders
(`android/`, `ios/`, etc.) are generated by Flutter and are **not** checked
in yet. After cloning:

```bash
git clone https://github.com/qspcgonzales-arch/AcademiaHeightsFlutterDev.git
cd AcademiaHeightsFlutterDev

# Generate the Android project files without touching lib/ or pubspec.yaml
flutter create . --platforms=android --org com.tip.academiaheights

flutter pub get
flutter run
```

> `flutter create .` on an existing folder only fills in missing platform
> scaffolding — it will not overwrite `lib/`, `pubspec.yaml`, `assets/`, or
> this README. Once the team decides to commit `android/`, remove the
> relevant ignore lines from `.gitignore` and commit it, and this step goes
> away for everyone else.

### Opening it in Android Studio

1. **Welcome screen → Get from VCS** (or **File → New → Project from Version
   Control**).
2. Paste `https://github.com/qspcgonzales-arch/AcademiaHeightsFlutterDev.git`,
   pick a local folder, **Clone**.
3. Wait for indexing to finish.
4. If it is not recognized as a Flutter project: **Settings → Plugins**,
   install **Flutter** + **Dart**, restart.
5. Terminal: `flutter create . --platforms=android --org com.tip.academiaheights`
   then `flutter pub get`.
6. Pick a device from the dropdown and press **Run**.

## Project layout

See [`CLAUDE.md`](CLAUDE.md) for the full folder and data-structure
conventions. Short version:

```
lib/
├── screens/   Flutter widgets for every non-gameplay screen
├── game/      Flame components (player, tile map, NPCs, collision)
├── models/    Plain data classes (PlayerProfile, Question, SaveFile, ...)
├── state/     provider ChangeNotifier controllers
├── services/  shared_preferences read/write
├── data/      static course list + question banks
└── theme/     colors, text styles
```
